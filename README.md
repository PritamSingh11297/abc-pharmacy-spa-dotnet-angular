# ABC Pharmacy SPA

A Single Page Application for pharmacy inventory management built using ASP.NET Core Web API and Angular.

## Tech Stack

- ASP.NET Core (.NET 9)
- Angular 22
- Bootstrap 5
- JSON File Storage

## Features

- View Medicines
- Add Medicine
- Sell Medicine
- Search Medicines
- Low Stock Highlight
- Expiry Warning
- Responsive UI

## Run

### API

```bash
dotnet restore
dotnet run
```

### Angular

```bash
npm install
ng serve
```

Browse to:

```
http://localhost:4200
```
